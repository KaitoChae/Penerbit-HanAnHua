# Penerbit Yayasan Han An Hua — Website V11 Lite

Versi terang, responsif, dan siap GitHub Pages.

## GitHub Pages
Gunakan branch `main` dan folder `/docs` pada Settings → Pages.

## Isi utama
- Penerbit sejak 2017
- Katalog buku terbitan
- Layanan penerbitan
- Profil Direktur
- Proses: Kontak → Kirim Naskah → Review & Editing → Terbit
- Tombol WhatsApp tanpa form
- Peta Google Maps lokasi Penerbit Yayasan Han An Hua

Versi ini dioptimalkan untuk kecepatan: gambar WebP terkompresi, tanpa Google Fonts, tanpa blur/backdrop animation, tanpa parallax/tilt, dan hanya memakai animasi transform/opacity yang singkat. Google Maps tetap lazy-load.


V11 readability update: service numbers enlarged, header logo slightly enlarged, and ISBN text enlarged for easier reading.
