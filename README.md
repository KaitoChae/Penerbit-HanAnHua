# Penerbit Yayasan Han An Hua — Website V13 Mobile Contrast

Versi ringan, responsif, dan siap GitHub Pages.

## GitHub Pages
Gunakan branch `main` dan folder `/docs` pada Settings → Pages.

## Perubahan V13
- Kontras mobile diperbaiki agar teks tidak menyatu dengan background.
- Panel “Jenis naskah yang dapat diajukan” sekarang memakai hijau gelap dengan teks krem yang jelas.
- Background bagian layanan dibuat sedikit lebih teduh untuk mengurangi silau.
- Hero tetap fokus pada penerbitan: “Terbitkan naskah Anda menjadi buku.”
- Gambar utama memakai JPEG terkompresi sebagai format universal.
- JavaScript ditulis defensif dengan fallback untuk browser yang tidak mendukung IntersectionObserver, matchMedia, passive listener, atau requestAnimationFrame.
- Fallback CSS untuk ukuran, viewport, touch target, dan browser yang tidak mendukung `content-visibility`.
- Tetap ringan: tanpa Google Fonts, tanpa framework JavaScript, dan tanpa library animasi eksternal.
- Responsif untuk HP, tablet, laptop, dan desktop.
